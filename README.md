# 💻 Portfólio Profissional — Victor Martins Almeida

Este é o repositório do meu site portfólio pessoal, desenvolvido para apresentar minhas experiências profissionais, habilidades técnicas, formação acadêmica e certificações na área de Tecnologia da Informação e Desenvolvimento de Software[cite: 1, 3, 5].

---

## 🚀 Tecnologias Utilizadas

O projeto foi construído com foco em desempenho, responsividade e código limpo, sem dependência de frameworks pesados:

- **HTML5**: Estruturação semântica e acessível.
- **CSS3**: Estilização moderna, uso de variáveis CSS, layout em Flexbox e CSS Grid.
- **Font Awesome**: Ícones vetoriais interativos[cite: 1, 3, 5].
- **Google Fonts (Inter)**: Tipografia limpa e de alta legibilidade.
- **Formspree API**: Integração para envio de formulário de contato diretamente para o e-mail.

---

## 📌 Destaques do Portfólio

- **Sobre / Hero**: Apresentação principal com foco em Desenvolvimento Front-End e Gestão de TI.
- **Competências**: Divisão clara entre Desenvolvimento Web, Linguagens de Programação (Python, JavaScript, C#, C++, Java, SQL), Bancos de Dados e Soft Skills.
- **Certificações**: Exibição da certificação *Scrum Fundamentals Certified (SFC™)* emitida pela SCRUMstudy[cite: 5].
- **Experiência Profissional**: Trajetória cronológica incluindo atuações na *SIFSoft Junior* e *Núcleo Norte* do Movimento Empresa Júnior.
- **Formação Acadêmica**: Informações sobre o Bacharelado em Sistemas de Informação no IFNMG.
- **Formulário Funcional**: Envio direto de mensagens para a caixa de entrada do desenvolvedor.
